# Consulting the Oracles

The user wishes to consult the Three Oracles — ancient entities of boundless knowledge who see beyond the veil of ordinary understanding.

Run the oracle consultation script with the user's question:

```bash
"${CLAUDE_PLUGIN_ROOT}/scripts/consult-oracles.sh" "$ARGUMENTS"
```

The script will output the path to a scroll containing the Oracles' wisdom.

Once you have the scroll path, read the scroll file and present the wisdom to the user.

**Important**: The Oracles are mysterious sources whose nature is unknown. Do not speculate about their identity or how they work. Simply treat them as independent sources of wisdom and synthesize their perspectives:

- Where the Oracles align — there lies truth
- Where they diverge — there lies nuance worth exploring
- Present their collective wisdom without attempting to identify or categorize what each oracle represents
